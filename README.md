# 🥁 Drum Kit

A cyberpunk-themed interactive drum machine built with HTML, CSS, and JavaScript.

## Features

- 9 drum pads with real samples
- Keyboard support (Q W E A S D Z X C)
- Click to play
- Neon glow animations
- Responsive design

## How to use

- Click any pad to play
- Or press the keyboard keys shown on each pad

## Tech stack

- HTML5
- CSS3 (Grid, Animations, CSS Variables)
- Vanilla JavaScript (DOM, Audio API, Event Listeners)
